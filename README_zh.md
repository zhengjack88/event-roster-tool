# 赛事志愿者物资与名单核验工具 (Event Roster Tool)

[English](README.md) | [在线演示 (默认英文)](https://zhengjack88.github.io/event-roster-tool/) | [在线演示 (中文版)](https://zhengjack88.github.io/event-roster-tool/index_zh.html)

> 🏃 **专为马拉松、越野赛、骑行、嘉年华等大型赛事的现场志愿者与管理者打造。**  
> 极速核验身份、发放物资、统计尺码、按岗位分发名单。纯前端单文件，**零依赖、零后端、零配置、彻底离线可用**。

---

## 🌟 最新核心特性（v2.0 全新升级）

### 1. 🔗 管理者岗位分发中心（岗位数据物理隔离）
- **自动聚类提取**：导入总表后，系统智能归类所有岗位（如：检录组、物资组、医疗站、计时组等）。
- **📦 一键导出单岗位离线 HTML**：管理员可直接导出独立打包文件（如 `赛事核验_检录组_烘焙版.html`），内置该组名单，发到微信群，**志愿者打开只能查本组数据，互不干扰、物理级隔离**。
- **📱 微信扫码一键带走**：内置 LZ-String 离线高倍压缩算法，岗位名单直接压缩为专属二维码/链接。志愿者手机微信扫一扫，瞬间将名单同步到手机本地缓存，**全赛道无信号/断网也能秒查**。

### 2. 📲 iOS / Safari 原生级体验（PWA 桌面固化）
- **零下载、零安装**：全面遵循 PWA 标准规范，内置详细的傻瓜式图文指引。
- **添加到主屏幕**：志愿者在 Safari 中点击「分享 ➡️ 添加到主屏幕」，即可在手机桌面生成常驻 App 图标。
- **全屏无边框**：桌面打开如同原生 App，无任何浏览器网址栏和底部菜单干扰，即点即查。

### 3. 📁 智能 CSV 批量导入与动态映射
- 智能表头模糊匹配，支持将各种 Excel/CSV 表头自动识别并映射到标准字段（姓名、电话、组别/岗位、尺码、工作证号、备注）。
- 实时数据暂存与一键全量持久化至浏览器 LocalStorage，防止误关闭网页导致数据丢失。

### 4. ⚡ 毫秒级多维度即时检索
- 支持 **姓名**、**手机号（支持后4位尾号速查）**、**参赛号/工作证号**、**身份证** 多字段即时模糊检索。
- 手机端专属「✕ 一键清空」按钮，极大提升现场高频检索效率。
- 物资尺码（S / M / L / XL / 2XL / 3XL）即时分面筛选与人数动态统计。

### 5. 🔒 极致隐私与安全
- **100% 客户端本地计算**：无任何后端接口或第三方跟踪，名单绝不离开使用者的设备。
- 赛后支持「一键清空本地缓存」，快速安全销毁敏感数据。

## 🚀 快速上手

### 体验在线 Demo
- [在线演示 (默认英文)](https://zhengjack88.github.io/event-roster-tool/)
- [在线演示 (中文版)](https://zhengjack88.github.io/event-roster-tool/index_zh.html)

### 管理员使用流程（推荐方式）
1. 打开网页，点击 **「📁 批量导入 CSV」**，选择赛事总名单。
2. 确认字段对齐后完成导入。
3. 点击 **「🔗 岗位分发」**：
   - **方式 A（微信群发文件）**：点击各组的 **「📦 导出【XX组】单文件」**，直接将 HTML 文件发到各组微信群。
   - **方式 B（现场扫码）**：点击 **「📱 专属码 / 链接」**，志愿者微信直接扫码带走本组名单。

### 志愿者端（手机体验）
1. 微信点开收到的文件或扫码进入。
2. 点击微信右上角 **「···」** 选择 **「在 Safari 中打开」**。
3. 底部点击 **「分享」** 图标 ➡️ **「添加到主屏幕」**，桌面一键点击秒开。
